# AWTRIX NG Apps by Hank_the_Tank

Berry scripts for [AWTRIX NG](https://awtrix.de) clocks, mostly made for the **52×16 panel of the Ulanzi TC002**.

The easiest way to install them is the **Send to AWTRIX** button on each app's AWTRIX Hub page. This repository holds the source code, descriptions and previews.

| App | Version | What it does | AWTRIX Hub |
|---|---|---|---|
| [Beautiful Weather](BeautifulWeather/) | 3.0 | Animated weather symbols with pages for rain, wind, 3-day forecast, sun and moon (Open-Meteo, no key) | [Install](https://awtrix.de/script/O3xYAw5TPWWp) |
| [Sunrise Alarm](SunriseAlarm/) | 1.6 | Alarm clock with a silent sunrise, red night clock, two schedules and snooze | [Install](https://awtrix.de/script/xtRmQ4UuyR5r) |
| [LiveScore](LiveScore/) | 3.1 | Live football score of your team (ESPN) with community home and away kits, goal fireworks, jingle and referee whistles | [Install](https://awtrix.de/script/q3feTbek0lRu) |
